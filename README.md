# AA 账本

本地桌面记账工具：按用户组分账本，记录谁掏了钱，自动算人均、谁欠谁多少钱、以及谁该下一次掏钱。
无账号、无鉴权、不联网、不需要部署，数据只存在你自己电脑上。

## 使用

```bash
npm install
npm start
```

首次运行如果提示 `Electron failed to install correctly`，说明安装时没下载 Electron 本体（网络原因），补一次即可：

```bash
node node_modules/electron/install.js
```

## 打包成免安装程序

```bash
npm run pack
```

产物在 `release\aa-ledger-win32-x64\`，双击里面的 `aa-ledger.exe` 即用，不用装、不写注册表，
整个文件夹拷到别的 Windows 机器上也能跑（约 270MB，主要是 Electron 本体）。
数据位置不变，仍然是 `%APPDATA%\aa-ledger\aa-ledger-data.json`，所以在开发目录跑和在打包版里记的账是同一份。

打包脚本会优先用本地已经下载好的 Electron 压缩包（`npm install` 时就下过了），因此 GitHub 连不上也能打包；
如果本地没缓存，它会尝试联网下载。要出 32 位或其他平台的包：`node scripts/pack.mjs win32 ia32`。

## 概念

- **账本 = 用户组**：一次旅行、一个宿舍、一组合租室友各建一个账本，彼此完全隔离。
- **成员池**：名字输过一次就存进全局成员池，下一个账本直接搜索点选，不用重打。
- **「我」**：第一次启动会问你的名字。之后每个新账本自动把你算进成员里，人均按含你的人数算；「我」标签贴在结算表、流水和下拉框上，方便一眼看到自己。名字可以在「设置」里改，也可以在某个账本里把自己移出（会先确认）。
- **固定人均**：一笔支出 ÷ 账本当前人数。除不尽的零头按笔轮换分配，保证每人份额加起来恰好等于总额。
- **加人就是改人均**：成员页的输入框既是搜索也是添加，输入时下面是已有成员的候选，点一下或回车即加入；没有的名字回车会新建并存进成员池。加/减人后表头的人均、侧栏人数和结算表会同步更新。

## 结算页给你三样东西

1. **金额账**：每人已付、应负担、差额（应收 / 应补），以及最少的转账撮合建议。
2. **人情账**：每人掏过几次钱、谁替谁垫付过多少钱几笔、下一次建议由谁掏钱。
   钱算平了但一次钱都没掏过的人，会单独标成「钱平账·欠掏钱」。
3. **每笔人均**：逐笔列出总额、人均、每人份额，方便当场对账。

## 数据在哪

默认存在应用自己的目录里（Windows：`%APPDATA%\aa-ledger\aa-ledger-data.json`）。
想自己决定放哪里，去「设置 → 账本数据存放位置」点「改到别的位置…」，选一个 JSON 文件即可；
换位置时会问你要不要把现有账本一起带过去，旧文件不会被删除。「恢复默认位置」同样会问一次。
菜单「数据」里也有这两项，另外能「在文件夹中显示数据文件」和「导出备份 JSON」。

每次保存都是先写临时文件再改名，并留一份 `.bak`；文件损坏时会另存为 `.corrupt-时间戳` 并以空数据启动，不会覆盖掉原文件。
侧栏底部始终显示当前实际读写的文件路径，标了「（自定义位置）」就是你自己指定的那份。

## 两台设备之间倒数据

数据文件就是一个 JSON，格式在哪都一样，所以电脑和手机（或两台电脑）不用同步，各记各的，事后再并：

1. 在 A 上：「设置 → 导入 / 合并另一台的账本」点「导出一份 JSON」，把文件传到 B（微信文件、数据线、网盘都行）。
2. 在 B 上：同一处点「选择 JSON 文件…」，会先给你看一份试算报告——会新增几笔、几个账本、几个成员，哪些笔要保留本机版本——你确认了才真合并。
3. 合并只做加法：不删本机任何记录；成员先按 id、再按名字认人（「王小美」不会变成两个人）；同 id 的账本算同一本；撞了 id 的一笔保留本机那份，只在报告里列出来；对方设备上的「我」和界面状态不会被带过来。
4. 合并完按钮会变成「撤销刚才的合并」，只要这中间你没再记新的，一键回到合并前。

## 手机上怎么用

界面已经做了窄屏适配（≤720px：账本变顶部横滑、结算表一人一块、输入框 16px 不触发放大），
桌面端最小宽度 900px，所以手机排版不可能影响电脑。

在手机上装个能打开本地 HTML 的浏览器，把 `src/` 整个文件夹拷进去打开即可，数据存在浏览器 localStorage 里，
记完「导出一份 JSON」拷回电脑合并。（部分浏览器出于安全限制不让直接打开 `file://` 页面，真遇到就只能走 APK 那条路。）

要变成真正的 APK（Capacitor + Android 工具链，本机要多装 1.5～2GB）还没做，需要的话再说。

## 目录

```
electron/   主进程与预加载脚本（窗口、菜单、数据读写）
src/        渲染层：index.html + styles.css + js/
  js/calc.mjs    结算算法（纯函数，金额单位为「分」）
  js/store.mjs   数据模型、迁移与持久化
  js/app.mjs     界面渲染与交互
test/       算法与数据模型的单元测试
scripts/    打包脚本（不进包）
```

```bash
npm test
```

## 不想装 Electron 时

直接用浏览器打开 `src/index.html` 也能用：数据存在浏览器的 localStorage 里，侧栏会写「浏览器预览模式」，
「设置」里的存放位置三项按钮会置灰。适合快速看界面，不适合长期记账。
