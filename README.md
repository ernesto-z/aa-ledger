# AA 账本

本地桌面记账工具：按用户组分账本，记录谁掏了钱，自动算人均、谁欠谁多少钱、以及谁该下一次掏钱。
无账号、无鉴权、不联网、不需要部署，数据只存在你自己电脑上。

## 使用

```bash
npm install
npm start
```

首次运行如果提示 `Electron failed to install correctly`，说明安装时没下载 Electron 本体（网络原因），补一次即可：

```bash
node node_modules/electron/install.js
```

## 打包成免安装程序

```bash
npm run pack
```

产物在 `release\aa-ledger-win32-x64\`，双击里面的 `aa-ledger.exe` 即用，不用装、不写注册表，
整个文件夹拷到别的 Windows 机器上也能跑（约 270MB，主要是 Electron 本体）。
数据位置不变，仍然是 `%APPDATA%\aa-ledger\aa-ledger-data.json`，所以在开发目录跑和在打包版里记的账是同一份。

打包脚本会优先用本地已经下载好的 Electron 压缩包（`npm install` 时就下过了），因此 GitHub 连不上也能打包；
如果本地没缓存，它会尝试联网下载。要出 32 位或其他平台的包：`node scripts/pack.mjs win32 ia32`。

## 概念

- **账本 = 用户组**：一次旅行、一个宿舍、一组合租室友各建一个账本，彼此完全隔离。
- **成员池**：名字输过一次就存进全局成员池，下一个账本直接搜索点选，不用重打。
- **「我」**：第一次启动会问你的名字。之后每个新账本自动把你算进成员里，人均按含你的人数算；「我」标签贴在结算表、流水和下拉框上，方便一眼看到自己。名字可以在「设置」里改，也可以在某个账本里把自己移出（会先确认）。
- **固定人均**：一笔支出 ÷ 账本当前人数。除不尽的零头按笔轮换分配，保证每人份额加起来恰好等于总额。
- **加人就是改人均**：成员页的输入框既是搜索也是添加，输入时下面是已有成员的候选，点一下或回车即加入；没有的名字回车会新建并存进成员池。加/减人后表头的人均、侧栏人数和结算表会同步更新。

## 结算页给你三样东西

1. **金额账**：每人已付、应负担、差额（应收 / 应补），以及最少的转账撮合建议。
2. **人情账**：每人掏过几次钱、谁替谁垫付过多少钱几笔、下一次建议由谁掏钱。
   钱算平了但一次钱都没掏过的人，会单独标成「钱平账·欠掏钱」。
3. **每笔人均**：逐笔列出总额、人均、每人份额，方便当场对账。

## 数据在哪

默认存在应用自己的目录里（Windows：`%APPDATA%\aa-ledger\aa-ledger-data.json`）。
想自己决定放哪里，去「设置 → 账本数据存放位置」点「改到别的位置…」，选一个 JSON 文件即可；
换位置时会问你要不要把现有账本一起带过去，旧文件不会被删除。「恢复默认位置」同样会问一次。
菜单「数据」里也有这两项，另外能「在文件夹中显示数据文件」和「导出备份 JSON」。

每次保存都是先写临时文件再改名，并留一份 `.bak`；文件损坏时会另存为 `.corrupt-时间戳` 并以空数据启动，不会覆盖掉原文件。
侧栏底部始终显示当前实际读写的文件路径，标了「（自定义位置）」就是你自己指定的那份。

### 改错了能回退

- **自动留备份**：每次内容真的变了，先把改之前的整份账本存进数据文件旁的 `aa-ledger-backups\`，文件名带时间，最多留 20 份（旧的自动删）。
- **找回**：菜单「数据 → 从备份恢复…」挑一份即可；恢复前当前这份也会先备份，所以能来回跳。「打开备份文件夹」直接定位这些文件。
- **不覆盖别人的写入**：如果这个文件在你打开之后被另一个实例（比如同时开着开发版和打包版）改过，保存会被拦下——你的改动另存成 `aa-ledger-data.json.conflict-时间戳`，磁盘上那份原样保留，界面顶部给出红色提示。同一份数据只允许一个窗口在写（第二个启动只会把第一个唤到前台）。

## 改代码时怎么测（不会碰你的真账）

`npm start` 和打包版读写的是同一个真实文件，所以改代码时不要拿它做实验。用隔离出来的测试实例：

```bash
npm run start:test            # 数据写到 %TEMP%\aa-ledger-test\aa-ledger-data.json
npm run start:test -- --seed  # 顺便塞一个「测试账本」，含两笔示例支出
```

它靠两个环境变量实现，你自己想用也能直接设：

- `AA_LEDGER_DATA=<绝对路径>`：只读写这一个 JSON；设置页里「改到别的位置 / 恢复默认位置」会置灰，侧栏标「（测试用数据文件）」。
- `AA_LEDGER_USER_DATA=<绝对路径>`：应用自己的目录（配置、缓存）也一起挪走，和正式版互不干扰。

```bash
npm test                      # 29 个单元测试：结算算法、数据迁移、合并、备份与冲突保护
```

## 两台设备之间倒数据

数据文件就是一个 JSON，格式在哪都一样，所以电脑和手机（或两台电脑）不用同步，各记各的，事后再并：

1. 在 A 上：「设置 → 导入 / 合并另一台的账本」点「导出一份 JSON」，把文件传到 B（微信文件、数据线、网盘都行）。
2. 在 B 上：同一处点「选择 JSON 文件…」，会先给你看一份试算报告——会新增几笔、几个账本、几个成员，哪些笔要保留本机版本——你确认了才真合并。
3. 合并只做加法：不删本机任何记录；成员先按 id、再按名字认人（「王小美」不会变成两个人）；同 id 的账本算同一本；撞了 id 的一笔保留本机那份，只在报告里列出来；对方设备上的「我」和界面状态不会被带过来。
4. 合并完按钮会变成「撤销刚才的合并」，只要这中间你没再记新的，一键回到合并前。

## 手机上怎么用

界面已经做了窄屏适配（≤720px：账本变顶部横滑、结算表一人一块、输入框 16px 不触发放大），
桌面端最小宽度 900px，所以手机排版不可能影响电脑。

在手机上装个能打开本地 HTML 的浏览器，把 `src/` 整个文件夹拷进去打开也能用，数据存在浏览器 localStorage 里，
记完「导出一份 JSON」拷回电脑合并。（部分浏览器出于安全限制不让直接打开 `file://` 页面，真遇到就走下面 APK 这条路。）

## 装成手机 App（APK）

工程里有 `android/` 目录和 `.github/workflows/android.yml`：**本机不需要装 JDK、Android SDK 或 Android Studio**，
构建在 GitHub 的安卓环境里跑。

1. 打开仓库的 Actions 页 → 左边选「安卓 debug APK」→ 右侧「Run workflow」→ Run workflow。
   （往 main 推代码也会自动跑一次。）
2. 跑完在 Summary 页面下载 `aa-ledger-debug` 里的 `app-debug.apk`（几 MB），传到手机安装。
   小米澎湃OS 会提示「未知来源应用」，设置里允许这一次安装即可。
3. debug 包没有签名配置，只能自己装着用，不能上架，也不要在同一台手机上装第二个不同签名的版本。

手机版的数据存在应用自己的目录里（`Android/data/com.local.aaledger/files/aa-ledger-data.json`），
不需要存储权限，卸载应用会连它一起删掉，所以记一阵就「导出一份 JSON」发到微信或拷到电脑存着。
和电脑之间倒数据仍然走上一节那套「导出 → 选择 JSON 文件 → 看试算报告 → 合并」。

### 手机版界面（和桌面端不一样的地方）

桌面端账本在左侧栏一排铺开；手机上侧栏整个收起来，改成这样：

- **顶栏只有一个账本**：左边是印章式的 ¥ 标记，中间是当前账本名 + 你那笔的差额（应收绿、应补朱），
  点它弹出「选择账本」全屏面板 —— 可搜索、按最近记账时间排序，每张卡显示最近一次记账日期、
  你的差额和「欠掏 N 次」轮值提醒，右下角 ⋯ 能直接改名 / 换币种 / 删除，底部是「＋ 新建账本」。
- **导航沉底**：流水 / 结算 / 成员 / 设置 变成底部标签栏（带图标），账本名不再重复占一行。
- **记一笔走底部抽屉**：流水页原本那张大表单收进右下角浮动「＋ 记一笔」，点一下从底部升起，
  填完保存后抽屉保持开着、焦点回到金额，可以连着记；点遮罩或右上角 × 收起。
- 顶栏不再显示数据文件路径（太长挤占空间），要看路径去「设置」页。

手机端是一层独立的视觉（`styles.css` 里 `@media (max-width: 720px)` 那段，纸质底色 + 宋体标题），
桌面端最小宽度 900px，永远进不到这个分支，所以改手机样式不会影响电脑上的样子。

改完 `src/` 里的代码要重新同步一次再提交，CI 才能拿到新界面（本地跑，不用安卓工具链）：

```bash
npx cap sync android
```

## 目录

```
electron/   主进程与预加载脚本（窗口、菜单、数据读写）
  data-store.cjs 数据文件读写：滚动备份、损坏另存、外部改写时不覆盖
src/        渲染层：index.html + styles.css + js/
  js/calc.mjs    结算算法（纯函数，金额单位为「分」）
  js/store.mjs   数据模型、迁移与持久化（桌面 / 安卓 / 浏览器三条路径）
  js/app.mjs     界面渲染与交互
android/    Capacitor 生成的安卓工程（CI 里 gradle assembleDebug）
capacitor.config.json  网页目录与包名
.github/workflows/     出 debug APK 的构建流程
test/       算法、数据模型与安卓存储的单元测试
scripts/    打包脚本与测试启动脚本（不进包）
```

```bash
npm test
```

## 不想装 Electron 时

直接用浏览器打开 `src/index.html` 也能用：数据存在浏览器的 localStorage 里，侧栏会写「浏览器预览模式」，
「设置」里的存放位置三项按钮会置灰。适合快速看界面，不适合长期记账。
