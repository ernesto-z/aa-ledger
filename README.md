# AA 账本

本地桌面记账工具：按用户组分账本，记录谁掏了钱，自动算人均、谁欠谁多少钱、以及谁该下一次掏钱。
无账号、无鉴权、不联网、不需要部署，数据只存在你自己电脑上。

## 使用

```bash
npm install
npm start
```

首次运行如果提示 `Electron failed to install correctly`，说明安装时没下载 Electron 本体（网络原因），补一次即可：

```bash
node node_modules/electron/install.js
```

## 概念

- **账本 = 用户组**：一次旅行、一个宿舍、一组合租室友各建一个账本，彼此完全隔离。
- **成员池**：名字输过一次就存进全局成员池，下一个账本直接点选，不用重打。
- **固定人均**：一笔支出 ÷ 账本当前人数。除不尽的零头按笔轮换分配，保证每人份额加起来恰好等于总额。

## 结算页给你三样东西

1. **金额账**：每人已付、应负担、差额（应收 / 应补），以及最少的转账撮合建议。
2. **人情账**：每人掏过几次钱、谁替谁垫付过多少钱几笔、下一次建议由谁掏钱。
   钱算平了但一次钱都没掏过的人，会单独标成「钱平账·欠掏钱」。
3. **每笔人均**：逐笔列出总额、人均、每人份额，方便当场对账。

## 数据在哪

菜单「数据 → 打开数据所在目录」可直接定位；文件为 `aa-ledger-data.json`，
每次保存会留一份 `.bak`。同菜单里的「导出备份 JSON」可以把账本拷去别处。

## 目录

```
electron/   主进程与预加载脚本（窗口、菜单、数据读写）
src/        渲染层：index.html + styles.css + js/
  js/calc.mjs    结算算法（纯函数，金额单位为「分」）
  js/store.mjs   数据模型、迁移与持久化
  js/app.mjs     界面渲染与交互
test/       算法单元测试
```

npm test
